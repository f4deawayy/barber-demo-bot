# Barber Demo Bot 💈

Telegram-бот для онлайн-записи клиентов в барбершоп, салон красоты, к мастеру маникюра или репетитору.

## Что умеет

**Для клиента**
- Записаться в 4 шага: услуга → день → свободное время → имя и телефон
- Занятое время автоматически скрывается — двойных записей не бывает
- «Мои записи» — посмотреть и отменить свою запись одной кнопкой
- Цены, адрес и часы работы

**Для владельца**
- Мгновенное уведомление о каждой новой записи и отмене
- Команда `/admin` — все предстоящие записи по дням и общая сумма

## Технологии
Python 3.10+ без внешних библиотек (только стандартная библиотека), Telegram Bot API, хранение записей в JSON. Занимает ~20 MB памяти — работает даже на бесплатных серверах.

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather) и получи токен.
2. Скопируй `.env.example` в `.env` и впиши `BOT_TOKEN` (и свой `ADMIN_ID` — его покажет команда `/myid`).
3. Запусти:
   ```
   python bot.py
   ```
   На Windows можно просто дважды кликнуть `start.bat`.

## Настройка под свой бизнес
В начале `bot.py` меняются название, адрес, услуги с ценами, рабочие часы и выходные.
